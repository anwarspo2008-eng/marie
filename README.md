## Project Goals

This project aims to build a lightweight, self-hosted server designed to run on a home lab setup. 

- **Self-hosted deployment** — Run entirely within a home lab environment, giving full control over infrastructure, networking, and data.
- **Authenticated device access** — Devices connect to the server using a username and password, ensuring only authorized clients can interact with it.
- **Terminal-based tooling** — Once connected, devices can access and run a set of custom tools directly from the terminal, streamlining remote management and automation.
